02 / 准备素材

你带来内容。
模板负责让它动起来。

先准备这些，不必现在就安装任何软件。缺少照片时，可以在官网能力开放范围内匹配或生成。

01必需

4 张拥有使用权的照片：JPG 或 PNG，重要主体不要紧贴边缘。

02必需

3 个简短关键词：对应三组海报构图。

03必需

一组简短信息：活动名称、日期和地点，也可以换成项目信息。

04可选

可选：想使用的语言和品牌配色。

05可选

可选：配乐或短旁白。加入声音前让助手核对时长与使用权。

这个模板的适配边界
  • 现有编舞为四张照片、三组构图；增加照片不会自动增加场景。
  • 已核实的是 16:9 横屏。需要原生竖屏时，先选择合适的模板。
  • 照片槽接收图片，不能直接换成视频片段。
  • 默认画面时间轴为 13 秒。新配音需要按下载包的实际时长控制能力核对。

开始制作前，检查这些依赖
  • 一台电脑，以及可以处理本地文件的助手或运行器。纯聊天助手可以准备简报，再转交到本地制作。
  • 以下载包要求为准安装具体版本。这套模板使用 Python 适配器、Node.js、Playwright 的 Chromium 浏览器和 FFmpeg 导出。
  • 按包内依赖锁和 setup/check 流程检查环境。安装依赖前先说明并获得用户同意，不仅凭介绍页安装。
  • 首次配置可能较久：助手先检查系统和已有工具，只按包内依赖锁补齐缺少的项，验证短预览；后续复用环境。等待时可以继续准备照片与文字。

06 / THE .motion FORMAT

一条视频的结果是 MP4。
再次创作的起点是 .motion。

把动画工程、内容槽位、素材角色、依赖与使用说明装进一个可识别的模板包。拿到模板后，用自己的内容再次创作。

动画工程可替换内容素材与依赖使用指引.motion

不是 Apple Motion 文件。格式公开不等于每个模板及素材都采用开放许可。
