## 从这里开始

1. **看效果，确认适用.** 展览与活动预告 / 创意作品展示 / 照片故事与情绪板.
2. **到官网获取模板.** [打开对应的 MotionGit 页面](https://motiongit.com/@prism-studio/visual-art-c-collage), 注册或登录，在下载开放后获取个人 .motion 包。尚未开放时先准备素材与简报。
3. **交给助手.** 发给 Codex、豆包或其他助手这个 GitHub 地址和下面的提示。拿到模板后，在私密工作区提供文件或本地路径。
4. **计划 → 预览 → 成片.** 助手读取真实包、检查环境、匹配素材，先让你审阅计划与预览，再导出。

## 用户需要准备的素材

- **必需:** 4 张拥有使用权的照片：JPG 或 PNG，重要主体不要紧贴边缘。
- **必需:** 3 个简短关键词：对应三组海报构图。
- **必需:** 一组简短信息：活动名称、日期和地点，也可以换成项目信息。
- **可选:** 可选：想使用的语言和品牌配色。
- **可选:** 可选：配乐或短旁白。加入声音前让助手核对时长与使用权。

## 依赖与制作环境

- 一台电脑，以及可以处理本地文件的助手或运行器。纯聊天助手可以准备简报，再转交到本地制作。
- 以下载包要求为准安装具体版本。这套模板使用 Python 适配器、Node.js、Playwright 的 Chromium 浏览器和 FFmpeg 导出。
- 按包内依赖锁和 setup/check 流程检查环境。安装依赖前先说明并获得用户同意，不仅凭介绍页安装。
- 首次配置可能较久：助手先检查系统和已有工具，只按包内依赖锁补齐缺少的项，验证短预览；后续复用环境。等待时可以继续准备照片与文字。

纯聊天助手也能帮你完成文案和素材清单；需要实际导出时转交给可运行本地工具的助手或兼容运行器。

## 关于 .motion

![模板到成片的制作流程](assets/workflow.svg)

`.motion` 是可复用的视频制作配方：它将动画工程、可替换参数、素材角色、依赖、预设与说明放在一个可识别的包里。MP4 是一次制作的结果；.motion 让你用自己的内容再次制作。它不是 Apple Motion 文件。

[了解格式](FORMAT.md) · [完整协议](https://motiongit.com/spec) · [协议仓库](https://github.com/motiontemplates/motion-spec)

## 适配边界

- 现有编舞为四张照片、三组构图；增加照片不会自动增加场景。
- 已核实的是 16:9 横屏。需要原生竖屏时，先选择合适的模板。
- 照片槽接收图片，不能直接换成视频片段。
- 默认画面时间轴为 13 秒。新配音需要按下载包的实际时长控制能力核对。
