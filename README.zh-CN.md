## 准备什么

- **必需:** 4 张拥有使用权的照片：JPG 或 PNG，重要主体不要紧贴边缘。
- **必需:** 3 个简短关键词：对应三组海报构图。
- **必需:** 一组简短信息：活动名称、日期和地点，也可以换成项目信息。
- **可选:** 可选：想使用的语言和品牌配色。
- **可选:** 可选：配乐或短旁白。加入声音前让助手核对时长与使用权。

## 制作环境

- 一台电脑，以及可以处理本地文件的助手或运行器。纯聊天助手可以准备简报，再转交到本地制作。
- 以下载包要求为准安装具体版本。这套模板使用 Python 适配器、Node.js、Playwright 的 Chromium 浏览器和 FFmpeg 导出。
- 按包内依赖锁和 setup/check 流程检查环境。说明缺少的工具与预计下载，按用户授权和助手宿主规则操作，后续复用环境。

首次配置可能较久。让助手先检查已有环境，只补齐缺项并验证短预览，后续复用。

## 关于 .motion

MP4 是成片；**.motion 是可复用的视频制作模板**，将动画工程、内容槽位、素材、依赖与说明组织在一起，让你用自己的内容再次制作。 [格式协议 ↗](https://motiongit.com/spec)

MotionGit 还提供素材匹配、生图、配音与配乐查找等配套能力，按实际槽位、账号权限和报价使用。
